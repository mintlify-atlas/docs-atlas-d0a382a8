# Welcome to CalPal

CalPal is a cross-platform mobile application for tracking food purchases, nutritional intake, and personal health metrics. Built with React Native, Expo, and Redux Toolkit, CalPal helps you log foods via barcode scanning, manual entry, or AI-powered text input, while monitoring your spending and visualizing your weight/BMI trends over time.

<Note>
  **Privacy First**: All data is stored locally on your device. No data is sent to external servers.
</Note>

## Local-First Architecture

CalPal is built with privacy as a core principle:

- **All data stays on your device** - No cloud sync or external servers
- **No account required** - Start tracking immediately
- **Full control** - Export or delete your data anytime
- **Works offline** - Full functionality without internet (except barcode/AI lookups)

## Tech Stack

CalPal is built with modern, production-ready technologies:

- **React Native** with Expo for cross-platform mobile development
- **Redux Toolkit** for predictable state management
- **TypeScript** for type safety and better developer experience
- **WatermelonDB** for local-first database storage
- **Expo Camera** for barcode scanning
- **USDA FoodData Central API** for accurate nutritional data
- **Cloudflare Workers AI** for natural language food entry
