## Overview

The `Collapsible` component provides an expandable/collapsible section with a title and content area. It features a rotating chevron icon that indicates the current state and smooth animations.

## Features

- Toggle visibility of content with tap gesture
- Animated chevron icon rotation (0° → 90°)
- Optional default open state
- Theme-aware styling
- Accessible touch target

## Props

<ParamField path="title" type="string" required>
  The text displayed in the collapsible header.
</ParamField>

<ParamField path="defaultOpen" type="boolean">
  Controls the initial expanded state. Defaults to `false` (collapsed).
</ParamField>

<ParamField path="children" type="ReactNode" required>
  The content to display when the section is expanded.
</ParamField>

## Component Structure

From `components/ui/Collapsible.tsx:10-33`:

```tsx
export function Collapsible({ 
  children, 
  title, 
  defaultOpen = false 
}: PropsWithChildren & { title: string, defaultOpen?: boolean }) {
  const [isOpen, setIsOpen] = useState(defaultOpen);
  const theme = useColorScheme() ?? 'light';

  return (
    <ThemedView>
      <TouchableOpacity
        style={styles.heading}
        onPress={() => setIsOpen((value) => !value)}
        activeOpacity={0.8}>
        <IconSymbol
          name="chevron.right"
          size={18}
          weight="medium"
          color={theme === 'light' ? Colors.light.icon : Colors.dark.icon}
          style={{ transform: [{ rotate: isOpen ? '90deg' : '0deg' }] }}
        />

        <ThemedText type="defaultSemiBold">{title}</ThemedText>
      </TouchableOpacity>
      {isOpen && <ThemedView style={styles.content}>{children}</ThemedView>}
    </ThemedView>
  );
}
```

## Accessibility

The component uses `TouchableOpacity` with:
- `activeOpacity={0.8}` for visual feedback
- Large touch target (entire heading row)
- Clear visual state indication via chevron rotation

## Animation Details

The chevron icon rotates using a transform:
- **Collapsed**: `rotate: '0deg'` (pointing right)
- **Expanded**: `rotate: '90deg'` (pointing down)

The rotation happens instantly on tap, providing immediate visual feedback.
