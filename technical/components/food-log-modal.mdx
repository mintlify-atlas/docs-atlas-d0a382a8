## Overview

The `FoodLogModal` component provides a form interface for manually adding or editing food log entries. It includes fields for nutritional macros, cost, weight, and validates required inputs before submission.

## Features

- Support for both add and edit modes
- Form validation for required fields
- Nutritional macro inputs (calories, protein, carbs, fat)
- Cost and weight tracking
- Optional product image display
- Keyboard-aware layout for mobile
- Theme-aware styling

## Input Validation

```tsx
// Required: name, cost, weight, calories, protein
const isFormValid = !!(
  form.name &&
  form.cost &&
  form.weight &&
  form.calories &&
  form.protein

```

The submit button:
- Is disabled when any required field is empty
- Changes visual appearance based on validation state
- Displays reduced opacity when disabled

### Managing Form State

```tsx
const [manualForm, setManualForm] = useState({
  name: '',
  cost: '',
  weight: '',
  calories: '',
  protein: '',
  carbs: '',
  fat: '',
  image: '',
});

const handleManualSubmit = async () => {
  // Validate form
  if (!manualForm.name || !manualForm.cost || !manualForm.calories) {
    return;
  }
  
  // Create log entry
  const entry = {
    id: Date.now().toString(),
    name: manualForm.name,
    cost: parseFloat(manualForm.cost),
    weight: parseFloat(manualForm.weight),
    calories: parseFloat(manualForm.calories),
    protein: parseFloat(manualForm.protein),
    carbs: parseFloat(manualForm.carbs) || 0,
    fat: parseFloat(manualForm.fat) || 0,
    timestamp: new Date().toISOString(),
  };
  
  // Save to database/state
  await saveLogEntry(entry);
  
  // Reset form and close modal
  setManualForm({
    name: '',
    cost: '',
    weight: '',
    calories: '',
    protein: '',
    carbs: '',
    fat: '',
    image: '',
  });
  setManualModalVisible(false);
};
```

## UI Layout

The modal features:

1. **Drag Handle**: Visual indicator at the top for swipe-to-dismiss gesture
2. **Title**: Customizable modal title
3. **Product Image**: Optional thumbnail displayed when `form.image` is set
4. **Form Fields**: Scrollable list of input fields with icons
5. **Action Buttons**: Cancel and Submit buttons at the bottom

### Icon Indicators

Each field is accompanied by a relevant Material Community Icon:
- Currency (`currency-usd`) for Cost
- Weight (`weight-gram`) for Weight
- Fire (`fire`) for Calories
- Drumstick (`food-drumstick`) for Protein
- Bread (`bread-slice`) for Carbs
- Water (`water`) for Fat

## Keyboard Handling

The modal uses `KeyboardAvoidingView` to ensure form fields remain visible when the keyboard is open:

```tsx
<KeyboardAvoidingView
  behavior={Platform.OS === 'ios' ? 'padding' : 'height'}
  style={{ flex: 1, justifyContent: 'flex-end', margin: 0 }}
>
```

All numeric fields use `keyboardType="decimal-pad"` for optimal input experience.
