## Accessing Restaurant Menus

<Steps>
  <Step title="Navigate to Restaurant Tab">
    Tap the **Restaurant** tab in the bottom navigation bar.
  </Step>
  
  <Step title="Search Restaurants (Optional)">
    Use the search bar at the top to filter the restaurant list by name.
  </Step>
  
  <Step title="Select a Restaurant">
    Tap on a restaurant card to view its full menu.
  </Step>
</Steps>

## Filtering Menu Items

Use the powerful filtering system to find items that match your dietary goals:

### Available Filters

<CardGroup cols={2}>
  <Card title="By Name" icon="magnifying-glass">
    Search for specific menu items by typing in the search box
  </Card>
  <Card title="Calorie Range" icon="fire">
    Set minimum and maximum calorie limits
  </Card>
  <Card title="Protein Range" icon="drumstick-bite">
    Filter by protein content (g)
  </Card>
</CardGroup>

### How to Filter

<Steps>
  <Step title="Enter Search Term">
    Type a food name in the "Search by name" field (e.g., "chicken", "salad").
  </Step>
  
  <Step title="Set Calorie Limits">
    Enter values in "Min Cal" and "Max Cal" fields to filter by calorie range.
    
    Example: Min Cal: 300, Max Cal: 600 shows only moderate-calorie items.
  </Step>
  
  <Step title="Set Protein Limits">
    Use "Min Protein" and "Max Protein" to filter by protein content.
    
    Example: Min Protein: 20 shows only high-protein items.
  </Step>
  
  <Step title="View Results">
    The menu automatically updates as you type. Only matching items are displayed.
  </Step>
</Steps>

<Note>
All filters work together. Setting multiple filters shows only items that match ALL criteria.
</Note>

## Menu Item Information

Each menu item displays comprehensive nutritional data:

```text
Item Name: Big Mac
Calories: 550 | Protein: 25g | Carbs: 45g | Fat: 30g
Serving: 1 sandwich (219g)
```

### Data Included

- **Item Name** - Official menu name
- **Calories** - Total energy content
- **Protein** - Protein content in grams
- **Carbohydrates** - Total carb content in grams
- **Fat** - Total fat content in grams
- **Serving Size** (McDonald's only) - Standard portion description

## Collapsible Sections

Menu sections can be expanded or collapsed for easier navigation:

- **Tap section header** to toggle open/closed
- **Sections open by default** when viewing a menu
- **Filters apply across all sections** - empty sections are hidden

<Tip>
When using filters, sections with no matching items automatically disappear, making it easier to see your options.
</Tip>

## Returning to Restaurant List

To go back to the restaurant selection:

1. Tap the **"< Back to Restaurants"** link at the top of the menu
2. This returns you to the main restaurant list

## Performance Features

The menu system includes optimizations for smooth browsing:

- **Virtualized scrolling** - Only renders visible items
- **Pagination** - Loads 30 items at a time
- **Automatic loading** - More items load as you scroll down
- **Memoized filtering** - Fast response when changing filters

<Info>
Large menus (100+ items) are paginated automatically. Scroll to the bottom to load more items.
</Info>

## Data Sources

Restaurant menu data is:

- Sourced from **official restaurant nutrition information**
- Stored locally in JSON files: `assets/restaurants/mcdonalds.json` and `chickfila.json`
- Updated periodically to reflect menu changes
- Based on standard serving sizes

<Warning>
Nutritional values are for standard menu items. Customizations (extra cheese, no sauce, etc.) may alter the nutritional content.
</Warning>
